# 金融 RAG 与 Agent 研究

围绕金融资料检索、工具辅助分析和研究报告生成的大模型应用项目，项目说明以中文维护。

## 从这里开始

- [统一研究作品集](https://github.com/Walter-prog88/News_request)：VLA／世界模型、大模型／Agent、A股与ETF量化的集中入口。
- [金融 RAG 工程](Fin-RAG-Knowledge-Base/)：源代码、配置、模型后端与评测资料。根目录还保留早期行情和应用原型，它们不构成一个统一生产系统。

## 已实现的研究流程

使用FAISS向量与词法检索、BGE重排序、时效权重和可选HyDE查询改写。Python控制的工作流连接文档、行情、因子、风险与受限代码分析工具，通过结构化输出组织证据和报告，保留调用记录，并提供Streamlit与Ollama等后端接口。

工具调度主要由确定性流程控制，不宣称已完成自主ReAct／LangGraph循环或成熟自动投研平台。

## 数据与评测口径

工程树有 **3,031个处理后Markdown文件**，不是核实过的去重文档数；检索评测含 **60条从源片段生成的合成问答**，脚本支持Recall@k、MRR和NDCG，但没有核实到“Recall 72%→89%”的改善结果。

另有 **10条问题的云端／本地RAG对照**。质量评分由大模型评判，存在一条评分失败和原摘要分母不一致的问题，不能写成人工正确率或Agent任务完成率。

## 凭据与复现

根目录agent.py读取环境变量GEMINI_API_KEY，agent2.py读取OPENAI_API_KEY；变量名见 [.env.example](.env.example)，程序不会自动加载该文件。源码不应保存真实API密钥。

依赖、模型、索引和数据需按对应条款另行准备，各原型入口以所在目录为准。本次整理未运行模型或复算历史评测。第三方依赖归各自作者所有，历史回测和模型评分不构成稳定收益证明。
